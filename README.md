# Python Tutorials

This repository is a hands-on Python learning track built as a series of daily practice scripts. It covers the core basics of Python, data structures, functions, loops, object-oriented programming, and practical examples that help reinforce the concepts with small executable programs.

## Repository Overview

The project is organized as a collection of standalone Python files, each focused on a specific topic or lesson. The naming follows a daily-learning structure, such as:

- `Day 1.py`
- `day-3.py`
- `day-7-functions.py`
- `day-12-list-insert-update.py`
- `day-24-oop.py`
- `day-25-oop-day-2.py`

This makes it easy to follow a progression from beginner fundamentals to intermediate Python concepts.

## Learning Path

The repo covers topics including:

- Variables and data types
- Input and output
- Operators and conditions
- Functions and return values
- Lists, tuples, sets, and dictionaries
- Loops and range usage
- Object-oriented programming
- File handling basics
- Working with datetime and OS modules
- SQLite / database basics
- GUI development with Tkinter
- API introduction concepts

## Quick Start

Make sure Python 3 is installed on your machine.

### Run a script

On Windows:

```powershell
py "Day 1.py"
py day-7-functions.py
py "day-24-oop.py"
```

On macOS/Linux:

```bash
python3 "Day 1.py"
python3 day-7-functions.py
python3 day-24-oop.py
```

## Suggested Learning Order

1. Start from the earliest files and move in order.
2. Read the code, then run it to observe the output.
3. Modify the examples to experiment with new values and behaviors.
4. Continue to the more advanced files once the basics feel comfortable.
